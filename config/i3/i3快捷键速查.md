# i3 快捷键速查

这份文档只说明当前这台 Linux 机器上的 `i3` 配置快捷键。
配置文件位置是 [config](~/.config/i3/config)。

## 基本说明

- `Mod` 键 = `Super` 键，也就是大多数键盘上的 Windows 键。
- `Mod1` = `Alt` 键。
- 当前终端默认是 `kitty`。
- 当前应用启动器默认是 `rofi`。

## 启动与关闭

| 快捷键              | 作用                           |
| ------------------- | ------------------------------ |
| `Super + Enter`     | 打开 `kitty` 终端              |
| `Super + grave`     | 呼出或隐藏下拉终端（Quake 式） |
| `Super + q`         | 关闭当前窗口                   |
| `Super + l`         | 锁屏（i3lock-color）           |
| `Super + Escape`    | 电源菜单（锁屏 / 登出 / 重启 / 关机） |
| `Alt + Space`       | 打开 `rofi` 应用启动器         |
| `Ctrl + Alt + Space`| 打开 `rofi` 应用启动器         |

## 媒体与亮度

| 快捷键                    | 作用       |
| ------------------------- | ---------- |
| `XF86AudioMute`           | 静音切换   |
| `XF86AudioLowerVolume`    | 音量减 5%  |
| `XF86AudioRaiseVolume`    | 音量加 5%  |
| `XF86MonBrightnessDown`   | 亮度减 5%  |
| `XF86MonBrightnessUp`     | 亮度加 5%  |

## 截图（flameshot）

| 快捷键                  | 作用             |
| ----------------------- | ---------------- |
| `Super + Shift + S`     | 区域截图         |
| `Print`                 | 区域截图         |
| `Shift + Print`         | 全屏截图         |
| `Ctrl + Print`          | 当前显示器截图   |

## 剪贴板

| 快捷键        | 作用                                |
| ------------- | ----------------------------------- |
| `Ctrl + grave`| 打开或关闭 `CopyQ` 剪贴板浮动窗口   |

## 焦点移动

| 快捷键              | 作用               |
| ------------------- | ------------------ |
| `Super + Left`      | 焦点移动到左侧窗口 |
| `Super + Down`      | 焦点移动到下方窗口 |
| `Super + Up`        | 焦点移动到上方窗口 |
| `Super + Right`     | 焦点移动到右侧窗口 |

字母键那组焦点移动（h/j/k/;）已经关闭，避免和常用快捷键冲突。

## 移动窗口

| 快捷键                      | 作用               |
| --------------------------- | ------------------ |
| `Super + Shift + h`         | 把当前窗口移到左侧 |
| `Super + Shift + j`         | 把当前窗口移到下方 |
| `Super + Shift + k`         | 把当前窗口移到上方 |
| `Super + Shift + ;`         | 把当前窗口移到右侧 |
| `Super + Shift + Left`      | 把当前窗口移到左侧 |
| `Super + Shift + Down`      | 把当前窗口移到下方 |
| `Super + Shift + Up`        | 把当前窗口移到上方 |
| `Super + Shift + Right`     | 把当前窗口移到右侧 |

## 分屏与布局

| 快捷键                      | 作用                                      |
| --------------------------- | ----------------------------------------- |
| `Super + Ctrl + h`          | 水平分屏                                  |
| `Super + Ctrl + v`          | 垂直分屏                                  |
| `Super + e`                 | 在 split 布局之间切换（水平 / 垂直）       |
| `Super + s`                 | 切换为 stacking 布局（竖排标题栏）         |
| `Super + w`                 | 切换为 tabbed 布局（标签页）              |
| `Super + f`                 | 全屏切换                                  |
| `Super + a`                 | 聚焦父容器                                |
| `Super + Ctrl + Space`      | 在 tiling / floating 焦点模式间切换       |
| `Super + Shift + Space`     | 将当前窗口切换为 floating / tiling        |

## 工作区

| 快捷键                                         | 作用                         |
| ---------------------------------------------- | ---------------------------- |
| `Super + 1` 到 `Super + 5`                     | 切换到外屏工作区             |
| `Super + 6` 到 `Super + 0`                     | 切换到内屏工作区             |
| `Ctrl + Alt + 1` 到 `Ctrl + Alt + 5`           | 切换到外屏工作区（备用）     |
| `Ctrl + Alt + 6` 到 `Ctrl + Alt + 0`           | 切换到内屏工作区（备用）     |
| `Super + Shift + 1` 到 `Super + Shift + 0`     | 把当前窗口移动到对应工作区   |

当前工作区命名：

| 编号    | 名称    | 屏幕 |
| ------- | ------- | ---- |
| `1`     | `I`     | 外屏 |
| `2`     | `II`    | 外屏 |
| `3`     | `III`   | 外屏 |
| `4`     | `IV`    | 外屏 |
| `5`     | `V`     | 外屏 |
| `6`     | `VI`    | 内屏 |
| `7`     | `VII`   | 内屏 |
| `8`     | `VIII`  | 内屏 |
| `9`     | `IX`    | 内屏 |
| `10`    | `X`     | 内屏 |

工作区会自动路由到对应显示器（由 `routing.sh` 生成规则）。
插拔显示器时 `hotplug-watch.sh` 自动恢复布局，并记住每块屏幕的偏好位置（靠 EDID）。

## Scratchpad

| 快捷键                  | 作用                       |
| ----------------------- | -------------------------- |
| `Super + -`             | 显示 / 隐藏 scratchpad     |
| `Super + Shift + -`     | 把当前窗口送入 scratchpad  |

## Resize 模式

### 直接调整

| 快捷键                    | 作用     |
| ------------------------- | -------- |
| `Super + Alt + Left`      | 缩小宽度 |
| `Super + Alt + Right`     | 增加宽度 |
| `Super + Alt + Up`        | 缩小高度 |
| `Super + Alt + Down`      | 增加高度 |

### Resize 子模式

先按 `Super + r` 进入 resize 模式，然后：

| 按键              | 作用             |
| ----------------- | ---------------- |
| `h` / `Left`      | 缩小宽度         |
| `j` / `Down`      | 增加高度         |
| `k` / `Up`        | 缩小高度         |
| `;` / `Right`     | 增加宽度         |
| `Enter`           | 退出 resize 模式 |
| `Esc`             | 退出 resize 模式 |
| `Super + r`       | 退出 resize 模式 |

## 主题切换

| 快捷键            | 作用                              |
| ----------------- | --------------------------------- |
| `Super + Ctrl + b`| rofi 弹出主题列表，选中即切        |

切换内容：i3 窗口颜色、kitty 终端配色、polybar 颜色、控制中心 / 音乐面板样式、壁纸。

## i3 自身控制

| 快捷键                | 作用         |
| --------------------- | ------------ |
| `Super + Shift + c`   | 重载 i3 配置 |
| `Super + Shift + r`   | 重启 i3      |
| `Super + Shift + e`   | 退出 i3      |

## 常用命令

```bash
i3-msg reload
i3-msg restart
```

## 面板与脚本

| 功能               | 位置                                           | 说明                             |
| ------------------ | ---------------------------------------------- | -------------------------------- |
| 控制中心           | polybar 控制中心模块                           | GTK3 浮窗：音乐 / WiFi / 蓝牙 / 音量 / 电源 |
| 音乐播放器面板     | polybar 音乐模块                               | GTK3 浮窗：专辑封面 / 进度条 / 3 套皮肤 |
| 下拉终端           | `` Super + ` ``                                | kitty-dropdown，浮动居中 1400×720 |
| 通知系统           | GJS 自建，替代 dunst                           | DBus 通知 + 面板                  |
| 主题切换           | `Super + Ctrl + b`                             | rofi 菜单，一键换色 + 壁纸        |
| 显示器布局         | `display/layout.sh`                            | 支持上方 / 左侧 / 右侧 / 仅内 / 仅外 / 镜像 |

## 使用建议

- 优先记住这几组：
  `Super + Enter`、`` Super + ` ``、`Alt + Space`、`Super + Shift + h/j/k/;`、`Super + Ctrl + h/v`、`Super + r`、`Super + l`。
- `i3` 负责管理整个应用窗口。
- `kitty` 负责管理终端内部 pane 分屏。
