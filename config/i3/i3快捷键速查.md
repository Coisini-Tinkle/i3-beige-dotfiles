# i3 快捷键速查

这份文档只说明当前这台 Linux 机器上的 `i3` 配置快捷键。
配置文件位置是 [config](~/.config/i3/config)。

## 基本说明

- `Mod` 键 = `Super` 键，也就是大多数键盘上的 Windows 键。
- 当前终端默认是 `kitty`。
- 当前应用启动器默认是 `rofi`。

## 启动与关闭

| 快捷键            | 作用                 |
| ----------------- | -------------------- |
| `Super + Enter` | 打开 `kitty`       |
| `Super + grave` | 呼出或隐藏下拉终端 |
| `Alt + Space`   | 打开 `rofi` 启动器 |
| `Super + l`     | 锁屏，执行 `i3lock` |
| `Super + space`     | ulauncher |
| `Super + q`     | 关闭当前窗口         |

## 剪贴板历史

| 快捷键     | 作用                                |
| ---------- | ----------------------------------- |
| `Ctrl +\`` | 打开或关闭 `CopyQ` 剪贴板浮动窗口 |

## 截图

| 快捷键                | 作用           |
| --------------------- | -------------- |
| `Super + Shift + s` | 区域截图       |
| `Print`             | 区域截图       |
| `Shift + Print`     | 全屏截图       |
| `Ctrl + Print`      | 当前显示器截图 |

## 焦点移动

| 快捷键            | 作用               |
| ----------------- | ------------------ |
| `Super + Left`  | 焦点移动到左侧窗口 |
| `Super + Down`  | 焦点移动到下方窗口 |
| `Super + Up`    | 焦点移动到上方窗口 |
| `Super + Right` | 焦点移动到右侧窗口 |

说明：
字母键那组焦点移动已经关闭，避免和常用快捷键冲突。

## 移动窗口

| 快捷键                    | 作用               |
| ------------------------- | ------------------ |
| `Super + Shift + h`     | 把当前窗口移到左侧 |
| `Super + Shift + j`     | 把当前窗口移到下方 |
| `Super + Shift + k`     | 把当前窗口移到上方 |
| `Super + Shift + ;`     | 把当前窗口移到右侧 |
| `Super + Shift + Left`  | 把当前窗口移到左侧 |
| `Super + Shift + Down`  | 把当前窗口移到下方 |
| `Super + Shift + Up`    | 把当前窗口移到上方 |
| `Super + Shift + Right` | 把当前窗口移到右侧 |

## 分屏与布局

| 快捷键                    | 作用                                |
| ------------------------- | ----------------------------------- |
| `Super + Ctrl + h`      | 水平分屏                            |
| `Super + Ctrl + v`      | 垂直分屏                            |
| `Super + e`             | 在 split 布局之间切换               |
| `Super + s`             | 切换为 stacking 布局                |
| `Super + w`             | 切换为 tabbed 布局                  |
| `Super + f`             | 全屏切换                            |
| `Super + a`             | 聚焦父容器                          |
| `Super + Ctrl + Space`  | 在 tiling / floating 焦点模式间切换 |
| `Super + Shift + Space` | 将当前窗口切换为 floating / tiling  |

## 工作区

| 快捷键                                         | 作用                       |
| ---------------------------------------------- | -------------------------- |
| `Super + 1` 到 `Super + 0`                 | 切换到工作区               |
| `Super + Shift + 1` 到 `Super + Shift + 0` | 把当前窗口移动到对应工作区 |

当前工作区命名如下：

| 编号   | 名称     |
| ------ | -------- |
| `1`  | `term` |
| `2`  | `web`  |
| `3`  | `code` |
| `4`  | `doc`  |
| `5`  | `chat` |
| `6`  | `misc` |
| `7`  | `media` |
| `8`  | `files` |
| `9`  | `sys`   |
| `10` | `temp`  |

## Scratchpad

| 快捷键                | 作用                      |
| --------------------- | ------------------------- |
| `Super + -`         | 显示 scratchpad           |
| `Super + Shift + -` | 把当前窗口送入 scratchpad |

## Resize 模式

直接调整当前聚焦窗口大小：

| 快捷键                  | 作用     |
| ----------------------- | -------- |
| `Super + Alt + Left`  | 缩小宽度 |
| `Super + Alt + Right` | 增加宽度 |
| `Super + Alt + Up`    | 缩小高度 |
| `Super + Alt + Down`  | 增加高度 |

也可以使用原来的 resize 模式。

先按：

```text
Super + r
```

进入 resize 模式后可以用下面这些键调整窗口大小：

| 快捷键            | 作用             |
| ----------------- | ---------------- |
| `h` / `Left`  | 缩小宽度         |
| `j` / `Down`  | 增加高度         |
| `k` / `Up`    | 缩小高度         |
| `;` / `Right` | 增加宽度         |
| `Enter`         | 退出 resize 模式 |
| `Esc`           | 退出 resize 模式 |
| `Super + r`     | 退出 resize 模式 |

## i3 自身控制

| 快捷键                | 作用         |
| --------------------- | ------------ |
| `Super + Shift + c` | 重载 i3 配置 |
| `Super + Shift + r` | 重启 i3      |
| `Super + Shift + e` | 退出 i3      |

## 常用命令

```bash
i3-msg reload
i3-msg restart
```

## 使用建议

- 如果你准备长期使用平铺式窗口管理器，优先记住这几组：
  `Super + Enter`、`Alt + Space`、`Super + Shift + h/j/k/;`、`Super + Ctrl + h/v`、`Super + r`、`Super + l`。
- `i3` 负责管理整个应用窗口。
- `kitty` 负责管理终端内部 pane 分屏。
