# Kitty 快捷键速查

这份文档记录的是当前 [kitty.conf](~/.config/kitty/kitty.conf) 里已经配置好的自定义快捷键，主要用于 `splits` 分屏布局。

## 分屏

| 快捷键               | 作用     | 说明                           |
| -------------------- | -------- | ------------------------------ |
| `Ctrl + Shift + h` | 上下分屏 | 在当前 pane 基础上继续横向切分 |
| `Ctrl + Shift + j` | 左右分屏 | 在当前 pane 基础上继续纵向切分 |

## pane 间移动

| 快捷键             | 作用            |
| ------------------ | --------------- |
| `Ctrl + Alt + h` | 移动到左侧 pane |
| `Ctrl + Alt + j` | 移动到下方 pane |
| `Ctrl + Alt + k` | 移动到上方 pane |
| `Ctrl + Alt + l` | 移动到右侧 pane |

## 调整 pane 大小

| 快捷键                   | 作用               |
| ------------------------ | ------------------ |
| `Ctrl + Shift + Left`  | 当前 pane 向左收窄 |
| `Ctrl + Shift + Right` | 当前 pane 向右变宽 |
| `Ctrl + Shift + Up`    | 当前 pane 向上变高 |
| `Ctrl + Shift + Down`  | 当前 pane 向下变矮 |

## 关闭

| 快捷键               | 作用          |
| -------------------- | ------------- |
| `Ctrl + Shift + w` | 关闭当前 pane |

## 常用操作

| 命令                    | 作用            |
| ----------------------- | --------------- |
| `kitty @ load-config` | 重载 kitty 配置 |

## 快速做出常见布局

### 做出三列布局

1. 先打开一个 pane。
2. 连按两次 `Ctrl + Shift + v`。

### 做出“右侧再上下切一刀”的布局

1. 先做出三列布局。
2. 用 `Ctrl + Alt + l` 把焦点移动到最右边 pane。
3. 按 `Ctrl + Shift + h`，把最右边 pane 再切成上下两块。

## 备注

- 这些快捷键对应的是 `kitty` 自己的分屏，不是 `tmux` 的 pane。
- 当前布局模式已经固定为 `splits`，所以分屏会像 tmux 一样支持嵌套切分。
