笔记本卡死了怎么办？（通俗版）

2026-08-05 · 关于 coisini-KLVC-WXX9 这台笔记本的卡死问题。写给不懂 Linux 细节的你看，术语尽量都换成大白话。

先记住一件事：卡死 ≠ 电脑坏了 ≠ 必须断电

电脑"冻住"的时候，通常只是表面（桌面画面、鼠标键盘）卡住了，电脑的"内核"（最底层的系统）其实还活着。就像手机上一个 App 卡住不动，但手机本身没死——你不需要关机，找到办法把那个 App 杀掉就行。

所以卡死时，按顺序试下面几招，招招都比"强制断电"安全。真正用得到断电的情况，几乎不存在。

一、卡死了，一步步这样做

第 0 步：先干等 30 秒。 有时显卡自己在"自我抢救"，等几秒它自己就缓过来了。顺手按一下 NumLock（数字锁定键），看键盘灯亮不亮：灯还能亮 → 电脑没事，只是表面卡了，放心往下救；灯都不亮了 → 才是真死透，直接跳第 3 步。

第 1 步：切到一个黑屏的"备胎"界面，把桌面特效重启。

同时按 Ctrl + Alt + F3，会切到一个纯文字的登录界面。输入你的用户名和密码登录进去，然后敲这两行命令（一行敲完按回车，再敲下一行）：

# 第一行：只重启"毛玻璃/动画"这个特效程序，最可能救回来
systemctl --user restart picom

# 如果上面这行没反应，再敲这行：把整个桌面重启
sudo systemctl restart gdm

敲完应该就能回到桌面了。想切回图形界面，按 Ctrl + Alt + F1 或 F2。

第 2 步：还不行？在黑屏终端里敲一个词 freeze，它会自动保存数据并重启。

就在刚才那个黑屏终端（Ctrl+Alt+F3）里登录后，输入：

freeze

回车即可。它会自动：① 保存没写完的数据 → ② 干净重启；如果系统卡得连重启命令都没反应，它会自动改用内核级硬重启，把数据保护到最后一刻。已配免密码，不弹密码。

（如果哪天没配成功，也可以手动按三个"神仙键"，效果一样：左手按住 Alt，右手按 PrtSc（印屏键）再分别按 S、U、B —— 保存 → 保护磁盘 → 重启。这三个键在你这台电脑上本来就已开启。）

第 3 步：再不行，长按电源键 10 秒。 这是笔记本标准硬关机，由硬件芯片执行，比你想象的安全，一般不丢文件。按住别松手，直到屏幕全黑。

第 4 步（几乎用不到）：拆电池。 只有长按电源键都没反应才需要。这台机器基本到不了这一步。

为什么不用一上来就断电？ 因为强制断电 = 正写到一半的数据可能损坏，还让你白白损失"还能救回来"的机会。上面的招数最多花你一分钟，多数情况在第 1 步就回来了。

二、为什么会卡死（一句话解释）

你最近给电脑加了两个东西：① 窗口动画（窗口打开关闭会滑来滑去）和 ② 毛玻璃特效（窗口后面的内容模糊成一片）。这俩靠你笔记本的 NVIDIA 显卡（MX350）来算，而这套组合在 NVIDIA 显卡上是出了名地容易把桌面冻住。

所以：不是电脑坏了，是你刚装的特效和这块显卡合不来。 好消息是，特效是可以关的。

三、怎么试一下，看是不是它的锅

办法一（最直接）：把动画关掉，用几天看看。 只需把配置文件里的一行改成 "关"，再重启一下特效就行。关掉后毛玻璃还在，只是窗口动画没了，几乎不影响使用。

办法二（免费送的观察线索）：留意"是不是只插着电才卡"。 你这台电脑设置成：插电时特效全开（含毛玻璃），用电池时自动把毛玻璃关掉。所以如果插电才卡、拔了电就不卡——那毛玻璃基本就是元凶，实锤了。

办法三：下次卡死时，帮我记两个细节。 ① 按 NumLock，灯亮不亮？② 当时是插着电还是电池？有了这两条，下次就能直接判断是不是特效的锅。

四、总结成一张小抄

卡死了 → 看 NumLock 灯（亮=没事）
    ├─ 先等 30 秒
    ├─ Ctrl+Alt+F3 → 登录 → freeze          ← 保存数据并重启（首选）
    ├─ 想先抢救不重启？→ systemctl --user restart picom
    ├─ （或手动）Alt+PrtSc+S / U / B
    ├─ 长按电源键 10 秒
    └─ 拆电池（永远用不到）

排查 → 关动画试试 · 看是不是插电才卡

（给技术人员的备注：本机 kernel.sysrq=176，S/U/B 已启用、R/E/I/K 未启用；卡死根因疑似 picom-ft-labs 的 GLX + blur/动画在 NVIDIA 私有驱动上，属高置信推断、尚未实证。完整技术版见历史版本或直接问我。）
